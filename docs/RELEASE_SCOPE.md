# Release Scope

This repository is intentionally a minimum sufficient reproducibility release. It does not contain raw datasets, all checkpoints, all prediction tensors, all logs, proprietary Origin projects, third-party VINO code, manuscript automation, historical experiments, or the obsolete one-sided FNO implementation.

The processed numerical data in `results/` are locked public copies or documented deterministic compositions of locked public inputs. `results/LOCKED_RESULTS_MANIFEST.csv` records only public paths, release hashes, byte counts, and public source labels. The private release audit retains the complete local source-location provenance map.
